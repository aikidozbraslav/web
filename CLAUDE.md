## Project Overview

This is a static website for Aikido Zbraslav (an Aikido club) built with **Zola**, a fast static site generator written in Rust. The site uses DaisyUI and Tailwind CSS via CDN for styling.

**Language**: Czech (default_language = "cs" in config.toml)

## Development Commands

### Build and Serve
```bash
# Serve the site locally with live reload (default: http://127.0.0.1:1111)
zola serve

# Build the site for production (outputs to public/ directory)
zola build

# Check for errors without building
zola check
```

### Content Management
```bash
# Preview the site with draft content
zola serve --drafts

# Build with draft content
zola build --drafts
```

## Project Structure

### Core Directories
- **content/** - Markdown content files organized by sections
  - `_index.md` - Homepage content
  - `aktuality/` - News/updates section with its own `_index.md` and individual posts
  - `about.md`, `contact.md` - Static pages

- **templates/** - Tera templates (Zola's templating engine)
  - `base.html` - Base template with DaisyUI/Tailwind setup, defines the overall HTML structure
  - `navbar.html` - Navigation component (included in base.html)
  - `section.html` - Template for section pages (lists child pages)
  - `aktuality.html` - Custom template for the news section
  - `aktualita.html` - Template for individual news posts
  - Template selection is controlled by frontmatter in content files

- **static/** - Static assets (copied as-is to public/)
  - `css/` - Custom CSS (styles.css)
  - `img/` - Images (including aikido-kanji.svg logo)

- **public/** - Build output directory (gitignored, generated by `zola build`)

### Configuration
- **config.toml** - Main Zola configuration
  - `base_url` = "https://aikidozbraslav.cz"
  - RSS feeds enabled (`generate_feeds = true`)
  - Sass compilation disabled (uses CDN for CSS frameworks)
  - Custom variables in `[extra]` section

## Template System

Templates use **Tera** (similar to Jinja2/Django templates):
- Extend base template with `{% extends "base.html" %}`
- Define content blocks with `{% block content %}...{% endblock %}`
- Include partials with `{% include "navbar.html" %}`
- Access config with `{{ config.extra.site_name }}`
- Use `get_url(path='...')` for asset URLs to ensure proper path resolution

## Content Frontmatter

Sections (`_index.md`) use frontmatter to configure behavior:
```toml
+++
title = "Aktuality"
sort_by = "date"           # Sort child pages by date
template = "aktuality.html" # Template for the section page
page_template = "aktualita.html" # Template for child pages
+++
```

Pages can use:
- `title` - Page title
- `date` - Publication date (used for sorting)
- `draft = true` - Mark as draft (excluded from normal builds)

## Styling

The site uses:
- **DaisyUI** (component library) via CDN
- **Tailwind CSS** (v4 browser version) via CDN
- Light theme: `data-theme="light"` set on `<html>` tag in base.html:2
- Custom CSS in static/css/styles.css for additional styling

When modifying styles, prefer DaisyUI/Tailwind utility classes. Only add to styles.css for custom overrides.

## Key Architecture Notes

1. **No build tooling for CSS/JS** - All frameworks loaded via CDN, simplifying the build process
2. **RSS feed generation** - Automatically generated for content sections
3. **Responsive navbar** - Uses DaisyUI dropdown for mobile, horizontal menu for desktop
4. **Section-based content organization** - The aktuality/ section demonstrates how to create a blog-like listing with dated posts
5. **Asset handling** - Use `get_url(path='...')` in templates to reference static files, ensuring they work in both dev and production

## Deployment

The site is automatically deployed to **Cloudflare Pages** via GitHub Actions:
- Push changes to the GitHub repository
- Cloudflare Pages triggers a build using Zola
- Generated pages are automatically deployed to production

No manual deployment steps are required.

## Common Tasks

**Add a new page**: Create a `.md` file in content/ with appropriate frontmatter
**Add a news post**: Create a `.md` file in content/aktuality/ with title and date in frontmatter
**Modify navigation**: Edit templates/navlinks.html (included in navbar.html)
**Change site metadata**: Update config.toml `[extra]` section or meta tags in base.html
**Update logo/images**: Place files in static/img/ and reference with `get_url(path='img/filename')`
